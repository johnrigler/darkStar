## The hack beneath the category

Matthew should connect the hacker idea directly to Chisel.

A useful proposition is:

> The hacker looks for the place where social meaning exceeds technical necessity.

A cryptocurrency address is socially presented as a destination for money. Technically it is also a constrained, machine-valid address space.

That difference is the Chisel hack.

A second line can recur:

> Innovation often begins when someone mistakes a convention for an implementation detail.

The important shift is not simply cleverness inside an accepted abstraction. It is seeing that the accepted abstraction is not identical to the mechanism underneath it.

Matthew can introduce these substitutions:

money -> medium
address -> language
wallet -> identity
transaction -> publication
blockchain -> index
book -> executable object

The point is not that controversy proves an idea is good. The point is that technical progress often appears where convention and actual machine possibility do not align.
