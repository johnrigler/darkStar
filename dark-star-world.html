Dark Star

A world index for the papers, printed books, experiments, tools, and working notes. There is no single correct route through it.

World index · October 2026

Dark Star is not one book and not one paper. It is a set of connected objects built around the same question: what can people keep, reconstruct, verify, exchange, and continue when the institution or service that first presented the object is no longer assumed to survive?

How to think about the collection

The opening Dark Star argument now forms a four-chapter sequence. Chapter 1, There Is No Spoon, explains stack capture and Web 2.8. Chapter 2, The Address Is the Index, shows a concrete alternative reading of blockchain using readable ledger coordinates and real address-history examples. Chapter 3, No Gatekeeper, asks what that gives us: identity, reputation, payment, and replaceable services without one application owning the person. Chapter 4, The Book Is Not the Thing, turns the critique onto media itself and explains why Dark Star must become an executable physical/digital experience rather than only another book about doing something. Other essays remain separate lenses, including The Public Index and Recombined Agency.
