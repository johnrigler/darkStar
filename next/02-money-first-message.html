Money was the first message

Cryptocurrency discovered something larger than cryptocurrency.

The obvious discovery was money: a holder of a cryptographic key could authorize value transfer through a public network without requiring one private institutional ledger to define the transaction.

That use was important enough to finance global infrastructure. But a transaction is already more than an amount. It has addresses, signatures, ordering, identifiers, script conditions, and sometimes explicit data.

THIS KEY CONTROLS THESE COINS

can become

THIS PERSON WAS HERE
THIS DOCUMENT EXISTED
THIS NAME POINTS HERE
THIS OBJECT HAS THIS HISTORY

The ledger does not know which sentence is money and which sentence is literature. Protocol rules validate bytes and state transitions. People assign the surrounding meanings.

Dark Star does not ask readers to stop caring about money. Money is why the machinery became difficult to ignore.

The next question is simply: what else can the machinery carry?
