Code smaller

Chisel uses an architectural rule that belongs in the larger Dark Star argument: do not confuse institutional complexity with technical necessity.

A modern application can become legacy while it is still young if it accumulates enough dependencies, build systems, ownership boundaries, hidden state, and switching costs.

AI makes another approach practical. Instead of asking a model to generate more code inside every inherited layer, ask first:

Why does this layer exist?
Does the original constraint still exist?
Can the browser already do it?
Can the protocol already do it?
Can the layer be removed?

Chisel therefore prefers vanilla browser JavaScript, explicit network boundaries, local signing, static/IPFS-compatible distribution, small adapters, inspectable state, fixtures, and source that remains close to what actually runs.

The aim is not minimalism as style.

The aim is recoverability and legibility, including legibility to an AI that may need to reconstruct the project after the original conversation has disappeared.
