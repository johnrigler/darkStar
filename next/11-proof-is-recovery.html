Proof is recovery

A protocol is not demonstrated because its author can still operate the original application.

The stronger test is archaeological.

ledger record
      +
recoverable grammar
      +
independent interpreter
      =
durable protocol

Chisel succeeds only if another implementation can reconstruct meaningful artifacts after ignoring Chisel's local database and preferred interfaces.

The same test applies to Dark Star.

If a QR opens only one website, the website is still the center. If an identity exists only inside one application database, the application is still sovereign. If an IPFS object can be found only through one remembered gateway URL, the route has not been made durable enough.

Recovery converts a philosophical claim into an engineering claim.

Can the thing be found, interpreted, and verified after the convenience layer is gone?

The proof is not permanence in the abstract.

The proof is successful reconstruction.
