The instrument, not the cartridge

Dark Star is one publication built on a larger collection of tools and conventions.

CHISEL
ledger reader/writer
identity + signing tools
protocol experiments

MOGWAI
media-facing reader
streams + discovery

M64
compact symbolic recovery
language/protocol representation

PASSPORT
personal trail
physical/digital anchors

LANTERN
replaceable hosted activity
games as entry points

PUBLIC LEDGERS + IPFS
durable/shared substrate

The names are not intended to become mandatory infrastructure, and the tools are not supposed to become another stack that defines what a valid project must look like.

A healthy instrument can be replaced piece by piece. Another reader, server, interface, runtime, ledger adapter, or implementation should be able to preserve the durable objects and rules underneath.

If Chisel becomes a gate, replace Chisel. If Lantern becomes permanent infrastructure, replace Lantern. If Dark Star becomes a doctrine, fork it.

The tool succeeds when capability survives the tool.
