A book that does not end at agreement

Most books are allowed to succeed when they alter interpretation.

Dark Star sets itself a harder test.

It uses essays because explanation matters. It uses images because some structures are easier to see than to define. It uses myth because human beings organize large transitions through recurring symbolic forms. It uses source code because the machinery should remain inspectable.

But none of those is the final medium.

The book should behave more like a textbook laboratory, field manual, or boot disk.

interpretation
     +
operation
     +
recovery
     =
changed capability

A reader may reject the worldview and still complete the labs.

A reader may like the mythology and ignore the software.

A reader may fork the software and discard Dark Star entirely.

That last outcome is not necessarily failure.

If the instrument survives the cartridge, the architecture worked.
