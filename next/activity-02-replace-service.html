Lab 2: replace a service

Goal: prove that a provider is useful without making it sovereign.

  1. Choose one durable identifier: a txid, address, CID, or signed artifact.
  2. Resolve it using the service Dark Star normally suggests.
  3. Copy the durable identifier itself, not the page URL.
  4. Resolve the identifier through another provider, gateway, explorer, or local tool.
  5. Compare what changed and what remained invariant.

If no alternate provider can recover the object, write down the dependency you discovered. That is not failure. It is an architectural fact.

service A ─┐
service B ─┼─> same durable thing
local tool ┘

The point is not to abolish servers. The point is to make server replacement ordinary.
